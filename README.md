# CodeAlpha Hangman Game

A simple command-line Hangman game built using Python as part of my CodeAlpha internship.

## About the Project

The player has to guess a randomly selected word one letter at a time.

The game provides a maximum of 6 incorrect guesses. The player wins by guessing all the letters before reaching the limit.

## Features

- Randomly selects a word from a predefined list
- Displays the hidden word using underscores
- Allows the player to guess one letter at a time
- Tracks incorrect guesses
- Allows a maximum of 6 incorrect guesses
- Detects when the player wins
- Detects when the player loses
- Prevents invalid inputs
- Prevents guessing the same letter multiple times

## Technologies Used

- Python
- Random module
- Lists
- Loops
- Conditional statements
- Functions and variables
- User input
